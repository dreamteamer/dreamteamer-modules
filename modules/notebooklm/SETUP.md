# Setting up notebooklm

One setup unit (`dt status` lists it as `notebooklm`): the vendor CLI on PATH (blocked naming it until installed — the `using-notebooklm` skill says which), and a Google login that nothing local can prove — the line reads `configured` with "Google login unverified" until a notebook is actually reached. The sign-in is the owner's, through the vendor CLI; the unit has no action of its own.
