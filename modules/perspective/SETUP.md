# Setting up perspective

One setup unit (`dt status` lists it as `perspective`): the optional input `asana_pat` (ASANA_PAT) written into `.env` by `set-asana_pat` (a workspace-files effect; the value is never shown or committed). `configured` means the key is set — whether Asana accepts it is only known when a sync runs; `missing` means tickets stay out of the perspective, which is fine.
