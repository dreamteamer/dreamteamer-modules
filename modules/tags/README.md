# @dreamteamer/tags

The tags convention: a `tags` field is a list of free strings, lowercase and hyphenated, optionally
`key:value` with no space around the colon. Nothing validates a tag. One skill, no collection.

```bash
npm install @dreamteamer/tags
npx dreamteamer compile
python3 .dreamteamer/skills/working-with-tags/bin/tags.py   # the tags already in use
```

Contacts, tasks and meetings depend on it, because their descriptors point a writer at that script.
